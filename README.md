# peru-wallet-mvp-front-grupo2

Aplicacion web inicial de Peru Wallet construida con Angular 22.

## Requisitos

- Node.js compatible con Angular CLI 22
- npm

## Desarrollo local

```bash
npm install
npm start
```

Abre `http://localhost:4200/`. La aplicacion se recarga automaticamente al guardar cambios.

## Validacion

```bash
npm test
npm run build
```
